# PracticeChart design context

Audience: Doctors and front desk staff at a small private medical practice.
Use: Find a patient, book a visit, record care, retrieve documents, and print records.
Voice: Calm, precise, and careful. Use short, clear English.
Quality: A complete course application with polished daily workflows.
Direction: Light clinical workspace with a deep green navigation rail. Use strong text contrast, readable tables, and generous form spacing. Use a compact mobile navigation and visible keyboard focus. Do not use motion that slows repeated work. Use fictional data only.
Typography: Geist with a system sans-serif fallback. Five main text sizes.
Motion: Press feedback at 120ms. Drawers at 180ms. No repeated page entrance animation. Honor reduced motion.

## Revised direction after user review

The user found the first green sidebar layout too close to the earlier application. Use an ink-blue accent, warm paper surfaces, top navigation, a compact worklist, and segmented record section controls. Do not reuse a saved layout from the deleted application. Keep the same server permissions and verified workflows.
